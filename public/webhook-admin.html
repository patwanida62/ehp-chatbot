📋 Application ที่ลงทะเบียน

📡 ส่งต่อ LINE Webhook (ใช้ OA เดียวร่วมกันหลายระบบ)

① ใส่ URL นี้ใน LINE Developers Console → Messaging API → Webhook URL

② เพิ่ม Webhook URL ของแต่ละระบบด้านล่าง — ทุก event จาก LINE จะถูกส่งต่อพร้อมลายเซ็นเดิม
③ ทุกระบบต้องกรอก Channel Access Token และ Channel Secret ของ OA เดียวกัน ไม่งั้นระบบปลายทางจะปฏิเสธลายเซ็น
